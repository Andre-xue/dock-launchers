## 三、已修复问题

### P0

1. **全局快捷键 ID 冲突**：截图翻译/划词翻译/翻译实际触发 30 秒录屏，录屏快捷键注册失败。
   - 修复：显式 ID 映射 `@[@1,@2,@3,@5,@4,@6,@7,@8,@9]`，越界返回失败。
2. **视频合并只保留一段**：每段都新建轨道并插入 0 秒。
   - 修复：复用同一 video/audio track，按 `comp.duration` 追加；回归 8.133s。
3. **AI 接口 `error` 为字符串时崩溃**：AI 助手、图片问答、翻译、转写、会议纪要 5 处。
   - 修复：类型判断后再取 `message`。
4. **文件转换中修改列表崩溃**：后台枚举 `convertPaths` 时主线程增删。
   - 修复：开始时复制 `jobs` 快照，输出目录同样快照。
5. **更新安装先删除应用**：DMG 损坏会导致应用丢失。
   - 修复：暂存解压、`codesign --verify --deep --strict` 校验、原子替换、失败回滚旧包。

### P1

6. **压缩/解压死锁**：`waitUntilExit` 后才读管道，大目录必挂。
   - 修复：先 drain 输出/错误，再等待退出；压缩任务输出重定向空设备。
7. **剪贴板清空/暂停/收藏按钮无实现**。
   - 修复：补齐 4 个方法并修复清空入口。
8. **快速面板“分组应用”无响应**。
   - 修复：加入 `分组应用` 打开分支。
9. **配置导入/回滚丢数据**：只备份 lists + settings，场景/布局/自动化/提示词丢失。
   - 修复：导出、导入、回滚、导入前快照全部补齐 JSON 存储。
10. **自动化时间规则一分钟触发 3 次，优先级未执行**。
    - 修复：按 `yyyyMMddHH:mm` 每分钟最多一次；时间规则首条命中后停止。
11. **自定义菜单项无法排序、无每页上限**。
    - 修复：内置项+自定义项统一按保存顺序排序；每页最多 8 个。
12. **页面自定义点“取消”仍会隐藏页面**。
    - 修复：改为内存 pending，仅在保存时写偏好。
13. **图库超过 8 张无法滚动**。
    - 修复：文档高度按行数计算，支持全部图片滚动浏览。
14. **本地 Whisper 把 stderr 当日志/输出，可能死锁**。
    - 修复：模型可读性校验、stderr 丢弃、非 0 退出码返回错误。
15. **视频轮询失败后 busy 卡死**。
    - 修复：连续 3 次失败终止；超时/失败/取消状态大小写兼容；提交错误中文化。
16. **OpenAI 图片默认参数不兼容**：gpt-image-1 带 response_format 导致 400。
    - 修复：gpt-image 不传 response_format，尺寸映射 1536x1024/1024x1536。
17. **截图历史列宽超出、垃圾文件混入**。
    - 修复：列宽收窄；过滤 `-part`、`camera-`、`音轨`、`-nr-`、`-audio` 等。
18. **实时标注没有 Esc 关闭**。
    - 修复：支持 Esc 关闭；顶部工具栏仍可关闭。

### 第二轮风险修复

19. **截图权限预检**：全屏、区域、窗口、钉屏、滚动长截图、快速截图统一调用 `ensureScreenCapturePermission`，未授权直接提示。
20. **图片工具主线程阻塞**：`imageConvert:` 改为后台执行 `sips`，主线程只更新结果并打开目录。
21. **TTS 合成视频入口**：AI 配音新增「打开配音视频」按钮，直接打开合成后的 MP4。
22. **多轨视频字幕合成**：字幕烧录改为按 composition 的 video track 构建 `AVMutableVideoComposition`，不再依赖源 asset 的 trackID；回归导出 1.3MB MP4 成功。
23. **摄像头降噪失败循环**：增加 `captureNoiseAttempted` 一次性标记，失败也继续合成并恢复状态，不无限重试。
24. **配置导入 shell 注入**：导入配置时自动移除 `customType == shell` 的自定义菜单项。
25. **截图结果浮层布局**：扩大面板、重排按钮和关闭按钮，消除重叠。

### 第三轮风险修复

26. **更新安装去 shell 插值**：改为写入临时 `.sh` 文件，DMG/应用路径通过 `$1`/`$2` 位置参数传入，不再把路径拼进 `sh -c`。
27. **麦克风音量异步化**：读取/设置系统输入音量移到后台队列，避免开始/结束录制时卡主线程。
28. **多显示器区域选择**：框选层覆盖所有屏幕的并集；screencapture 坐标按主屏 frame 换算。
29. **钉屏截图**：截图前隐藏自身面板，截图完成后删除临时 `pin-*.png`。

### 第四轮安全与可用性修复

30. **AI 数据导出默认不含 API Key**：导出前询问；包含 Key 需应用密码认证；文件权限 0600。
31. **AI 数据导入合并**：优先按 `kid` 匹配，保留分类/模型/地址，空 Key 不覆盖原 Key，避免导入丢数据。
32. **第三方转写语言可选**：转写设置新增自动/中文/英文/日文；不再硬编码 `language=zh`。
33. **模型/地址可手动填写**：图片、视频、编辑的模型和 URL 字段允许在自动获取失败时输入。

### 第五轮收尾

34. **压缩/解压可取消**：保存当前 `NSTask`，新增「取消」按钮；取消后终止进程、停止 spinner、显示“已取消”。
35. **截图坐标与钉屏清理**：区域选择覆盖所有屏幕并集，按主屏 frame 换算；钉屏隐藏自身面板并清理临时文件。
36. **压缩/解压管道已改为先读取再等待**，避免大目录死锁。

### 第六轮收尾

37. **PDF 合并/拆分异步化**：增加 spinner 与状态文本，避免大 PDF 卡住主界面。
