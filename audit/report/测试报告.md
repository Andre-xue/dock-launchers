## 三、已修复问题

### P0

1. **全局快捷键 ID 冲突**：截图翻译/划词翻译/翻译实际触发 30 秒录屏，录屏快捷键注册失败。
   - 修复：显式 ID 映射 `@[@1,@2,@3,@5,@4,@6,@7,@8,@9]`，越界返回失败。
2. **视频合并只保留一段**：每段都新建轨道并插入 0 秒。
   - 修复：复用同一 video/audio track，按 `comp.duration` 追加；回归 8.133s。
3. **AI 接口 `error` 为字符串时崩溃**：AI 助手、图片问答、翻译、转写、会议纪要 5 处。
   - 修复：类型判断后再取 `message`。
4. **文件转换中修改列表崩溃**：后台枚举 `convertPaths` 时主线程增删。
   - 修复：开始时复制 `jobs` 快照，输出目录同样快照。
5. **更新安装先删除应用**：DMG 损坏会导致应用丢失。
   - 修复：暂存解压、`codesign --verify --deep --strict` 校验、原子替换、失败回滚旧包。

### P1

6. **压缩/解压死锁**：`waitUntilExit` 后才读管道，大目录必挂。
   - 修复：先 drain 输出/错误，再等待退出；压缩任务输出重定向空设备。
7. **剪贴板清空/暂停/收藏按钮无实现**。
   - 修复：补齐 4 个方法并修复清空入口。
8. **快速面板“分组应用”无响应**。
   - 修复：加入 `分组应用` 打开分支。
9. **配置导入/回滚丢数据**：只备份 lists + settings，场景/布局/自动化/提示词丢失。
   - 修复：导出、导入、回滚、导入前快照全部补齐 JSON 存储。
10. **自动化时间规则一分钟触发 3 次，优先级未执行**。
    - 修复：按 `yyyyMMddHH:mm` 每分钟最多一次；时间规则首条命中后停止。
11. **自定义菜单项无法排序、无每页上限**。
    - 修复：内置项+自定义项统一按保存顺序排序；每页最多 8 个。
12. **页面自定义点“取消”仍会隐藏页面**。
    - 修复：改为内存 pending，仅在保存时写偏好。
13. **图库超过 8 张无法滚动**。
    - 修复：文档高度按行数计算，支持全部图片滚动浏览。
14. **本地 Whisper 把 stderr 当日志/输出，可能死锁**。
    - 修复：模型可读性校验、stderr 丢弃、非 0 退出码返回错误。
15. **视频轮询失败后 busy 卡死**。
    - 修复：连续 3 次失败终止；超时/失败/取消状态大小写兼容；提交错误中文化。
16. **OpenAI 图片默认参数不兼容**：gpt-image-1 带 response_format 导致 400。
    - 修复：gpt-image 不传 response_format，尺寸映射 1536x1024/1024x1536。
17. **截图历史列宽超出、垃圾文件混入**。
    - 修复：列宽收窄；过滤 `-part`、`camera-`、`音轨`、`-nr-`、`-audio` 等。
18. **实时标注没有 Esc 关闭**。
    - 修复：支持 Esc 关闭；顶部工具栏仍可关闭。

## 四、仍保留的风险

| 风险 | 说明 | 建议 |
|---|---|---|
| 更新安装 shell 插值 | 路径仍拼进 `/bin/sh -c`，理论上可注入 | 改为写独立脚本文件+转义/白名单 |
| 配置导入自定义命令 | 导入的 shell 自定义项可执行 | 导入时拒绝 shell 类型或要求密码确认 |
| 主线程阻塞 | 图片转换、系统音量 AppleScript 在主线程 | 改异步任务+进度/取消 |
| 截图权限预检 | 全屏/区域/长截图只靠 screencapture 返回值 | 统一 `CGPreflightScreenCaptureAccess` |
| 摄像头合成失败重试 | 降噪失败可能循环生成临时文件 | 增加一次性标志/失败收尾 |
| 多显示器坐标 | 区域/钉屏/长截图使用主屏高度 | 用 screen.frame.origin 换算全局坐标 |
| TTS 合成视频入口 | 生成后只能看状态，无“打开视频”按钮 | 增加打开/Finder 按钮 |
| 字母幕合成轨道 | 字幕烧录复用源 asset 的 videoComposition | 多轨 MOV 可能失败，应按 composition 轨构建 |
| 结果面板按钮重叠 | 5 个按钮与关闭/文件名区域重叠 | 重新排布 |
| 图片工具/压缩主线程 | sips/zip 等待阻塞 UI | 后台任务+进度条 |
